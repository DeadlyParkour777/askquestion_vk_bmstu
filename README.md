# Q&A форум
Django‑сервис вопросов и ответов: пользователи задают вопросы, отвечают, голосуют и отмечают правильные ответы. Есть теги, профиль с аватаром и лайв‑обновление ответов через Centrifugo.

## Стек и инфраструктура
Проект - монолит на Django, но запускается с внешними сервисами через `docker compose`:
- **app** - Django + Gunicorn (монолит)
- **nginx** - статика/медиа + прокси к приложению
- **db** - PostgreSQL 16
- **redis** - кеш и статистика
- **centrifugo** - real‑time канал новых ответов

## Старт
**Требования:** Docker + Docker Compose.

1) Создать `.env` из шаблона:
```bash
cp .env.example .env
```
Или можно заполнить вручную

2) Запуск:
```bash
make compose-up
```

## Автозаполнение базы
Если проект запущен в докере, то можно быстро наполнить БД тестовыми данными:
```bash
make fill-db
```
Где `10` - коэффициент заполнения (пользователи = `ratio`, вопросы = `ratio * 10`, ответы = `ratio * 100`).

## Эндпоинты
Веб‑интерфейс:
- `/` - новые вопросы
- `/hot/` - горячие вопросы
- `/question/<id>/` - страница вопроса
- `/tag/<name>/` - вопросы по тегу
- `/ask/` - задать вопрос (нужна авторизация)
- `/login/`, `/signup/`, `/logout/`
- `/profile/edit/` - настройки профиля
- `/search/?q=...` - подсказки по поиску (JSON)

Админка:
- `/admin/`

Порты по умолчанию:
- `http://localhost:8080` - приложение через Nginx
- `http://localhost:8081` - `my_wsgi`
- `ws://localhost:8001/connection/websocket` - Centrifugo WebSocket

## Структура репозитория
- `ask_pupkin/` - настройки Django
- `qa/` - основное приложение (модели, формы, views)
- `templates/` - HTML‑шаблоны
- `static/` - статические файлы
- `nginx/` - конфиг Nginx
- `docker-compose.yml` - конфигурация Docker compose
- `centrifugo.json` - конфиг Centrifugo
